# Paper Builds

This directory keeps only the maintained paper variants:

- `neurips2026_preprint.tex` and `neurips2026_preprint.pdf` - arXiv-facing
  preprint with author information.
- `neurips2026_submission.tex` and `neurips2026_submission.pdf` - anonymized
  OpenReview/NeurIPS submission build.

Shared source files:

- `neurips_body.tex`
- `neurips_checklist.tex`
- `references.bib`
- `neurips_2026.sty`
- `figures/` containing the four PDF figures referenced by `neurips_body.tex`.

Generated LaTeX files, duplicate upload trees, source archives, reviewer-response
drafts, and supplementary package copies are intentionally not kept in the public
repository.
